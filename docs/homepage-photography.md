# Homepage photographic composition

Replaces the two generated house backgrounds with a photographic montage derived
from the artist's original house photographs. The supplied set was confirmed
complete before this work began. The closest flower and frontal window photographs
provide the published pixels; wider photographs were reviewed for context.

The source files used are `1-Photo-8.jpg` and `2-Photo-9.jpg` from the final uploaded
reference group. Originals remain untouched in the private working files and are
not copied wholesale into this public repository. Published WebP derivatives
contain no original EXIF metadata.

This is a composed photographic facade, not an unaltered documentary photograph
of the house. Siding, sash panels, trim, reflected foliage, and planting are cropped,
resized, and arranged to fit the existing desktop/mobile navigation geometry.
Some photographic panel portions are reused. Natural window reflections replace
the previous generated cloud scenery; no new sky or roof is invented. Plant
cutouts and narrow edge feathering are conventional photo compositing. No image
generation, generative fill, painted texture, saturation boost, or golden color
grading is used. The actual siding wear, timber, plants, and photographic lighting
come from the original images.

Desktop: 1536 × 1024. Mobile: 1024 × 1536. Existing HTML, CSS, JavaScript, layout,
approved Option B title, and full-window navigation hit areas are unchanged.
Original artwork, exhibition records, and Spring files are unchanged.

Browser/device rendering still needs review through the separate Sites preview.
